## ✨ Features
- **Interactive Full-Screen Hero Slider**: Dynamic carousel showcasing authentic shop photography and storefront displays.
- **Blended Header Navigation**: Transparent top navbar transitioning to a clean frosted white header on scroll.
- **Interactive Product Catalog**: Instant category filtering, real-time live search, and modal view with price enquiry buttons.
- **Direct Enquiries**: One-click Phone Call and WhatsApp enquiry integration.
- **Shop Gallery**: High-resolution authentic photos of the shop interior and showroom counters.
- **Responsive Design**: Optimized for smartphones, tablets, and desktop displays.
- **Zero Heavy Frameworks**: Built with clean, accessible semantic HTML5, modern CSS3, and lightweight Vanilla JavaScript.

## 🚀 Running Locally
Open `index.html` directly in any web browser, or serve using any static web server:
```bash
# Using Node.js
npx serve .

# Or using Python
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
